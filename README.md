# The Tired Dark Lord: A 100-Word Villain Monologue

Entry for make.fun competition
`u-kevin-the-tired-dark-lord-a-100-word-villain-58b4f3cb`.

`main.ts` (Node 22, pure stdlib, no network) writes one original
~100-word monologue to `/output/entry.txt`: an exhausted dark lord,
three centuries into an eclipse ritual, stalling the hero on the
stairs until next Tuesday.

Run: `node main.ts`
